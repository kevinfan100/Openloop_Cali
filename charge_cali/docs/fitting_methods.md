# 擬合方法推導與比較

> 模型: `H(x) = a² / (x + b)²`，線性化: `y = 1/√H` → `x = a·y - b`

---

## 方法 A: 無約束最小二乘法 (教授公式)

### 目標

最小化 x 方向殘差平方和：

```
S = Σ (x_i - a·y_i + b)²
```

### 推導

對 a 和 b 分別偏微分 = 0，得 Normal Equations：

```
∂S/∂a = 0:   Σ y_i·(x_i - a·y_i + b) = 0
∂S/∂b = 0:   Σ (x_i - a·y_i + b) = 0
```

從 ∂S/∂b = 0 得**質心條件**：

```
x̄ = a·ȳ - b     ──── (B)
→ b = a·ȳ - x̄
```

將 (B) 代入 ∂S/∂a = 0，整理得：

```
mean(x·y) - x̄·ȳ = a·(mean(y²) - ȳ²)
```

### 結果

```
a = (mean(x·y) - mean(x)·mean(y)) / (mean(y²) - mean(y)²)
b = a·mean(y) - mean(x)
```

### 性質

- 使用**全部 N 個數據點**最小化殘差
- 擬合線通過質心 (x̄, ȳ)
- **不保證通過任何特定數據點**

---

## 方法 B: 約束最小二乘法 (通過第一點)

### 目標

最小化 x 方向殘差平方和，**且強制通過第一個數據點** (x₁, y₁)：

```
S = Σ (x_i - a·y_i + b)²
約束: x₁ = a·y₁ - b
```

### 推導

**Step 1** — 用約束消去 b：

```
b = a·y₁ - x₁
```

代入 S：

```
S = Σ (x_i - a·y_i + a·y₁ - x₁)²
  = Σ ((x_i - x₁) - a·(y_i - y₁))²
```

令 Δx_i = x_i - x₁，Δy_i = y_i - y₁：

```
S = Σ (Δx_i - a·Δy_i)²
```

**Step 2** — 對 a 偏微分 = 0：

```
∂S/∂a = -2·Σ Δy_i·(Δx_i - a·Δy_i) = 0
→ Σ (Δx_i · Δy_i) = a · Σ (Δy_i²)
```

### 結果

```
a = Σ(Δx_i · Δy_i) / Σ(Δy_i²)
b = a · y₁ - x₁

其中 Δx_i = x_i - x₁,  Δy_i = y_i - y₁
     x₁ = 10 μm,  y₁ = 1/√H(10μm)
```

### 性質

- 只剩 1 個自由度 (a)，b 由約束決定
- 擬合線**精確通過** (x₁, y₁)
- **不一定通過質心**——這是為了通過第一點而付出的代價

## 擬合結果 (10 ~ 500 μm, 12 點)

| 頻率 | a (教授) | a (約束) | b (教授) [μm] | b (約束) [μm] |
|------|----------|----------|---------------|---------------|
| 0.1 Hz | 604.26 | 595.30 | 1502.25 | 1474.82 |
| 1 Hz | 604.56 | 600.38 | 1503.20 | 1490.37 |
| 10 Hz | 603.42 | 592.60 | 1499.95 | 1466.85 |
| **Mean ± Std** | **604.08 ± 0.59** | **596.09 ± 3.95** | **1501.80 ± 1.67** | **1477.35 ± 11.96** |

### 觀察

- **教授公式的跨頻率一致性較高**：b 的 Std = 1.67 μm vs 約束 LS 的 11.96 μm
- 約束 LS 的 b 偏低 ~2%，a 偏低 ~1.5%
- 兩種方法差異小，因為短距離數據接近完美直線，第一點偏差僅 ~5 μm
